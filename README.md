# Quran Memorization Assets

مستودع الأصول العام لتطبيق **Quran Memorization Online**. يحتوي على نص القرآن والتوقيتات وملفات التلاوة التي يستطيع تطبيق Android قراءتها أو تنزيلها عند الطلب.

## بنية الأصول

| المسار | الاستخدام |
|---|---|
| `quran/quran_content.json` | النص العربي الكامل وبنية السور والآيات والكلمات |
| `timings/Alafasy_128kbps.json` | توقيتات المقاطع والكلمات من quran-align |
| `audio/Alafasy_128kbps/{surah:03d}{ayah:03d}.mp3` | ملف الصوت المرجعي لكل آية |
| `manifest.json` | إصدار الأصول، الأحجام، والروابط التي يستخدمها التطبيق |

## أوضاع التطبيق

يمكن للتطبيق تشغيل ملف الآية مباشرة من رابط GitHub العام دون إنشاء نسخة دائمة في التخزين المحلي. ويمكنه بدلاً من ذلك تنزيل النص أو التوقيتات أو النموذج أو ملف/حزمة الصوت التي يختارها المستخدم إلى `filesDir`، ثم إعادة استخدامها دون اتصال لاحقاً. كما يمكن حذف أي حزمة محلية وإعادة تنزيلها، مع حفظ checksum وحالة التنزيل.

## المصدر

النص مبني على Tanzil Quran Text Version 1.1، ثم جرت مواءمة كل token القابل للمقارنة حرفياً مع `word_arabic` في quran.com-images، بما في ذلك التشكيل والعلامات والرسم، مع إبقاء البسملات الأربعة التي يعرضها التطبيق كسطر مستقل في بدايات السور. شملت المواءمة تغيير `يَٰصَىٰحِبَىِ` في الآيتين 12:39 و12:41، وتوحيد الكلمات المركبة التي يضعها مرجع الصور في token واحد، وتحديث `matchText` عند الحاجة. لذلك يعلن `quran_content.json` أن `canonicalTextUnchanged=false`، ويحدد `manifest.json` الإصدار `2026.08.24.2`. التوقيتات مأخوذة من إصدار quran-align المقفل. ملفات MP3 مأخوذة من EveryAyah للاستخدام في التطبيق التجريبي. يجب مراجعة الحقوق وشروط إعادة التوزيع لكل قارئ وملف قبل أي نشر تجاري.

## ملاحظة التخزين

ملفات MP3 هي ملفات مضغوطة أصلاً ويبلغ مجموعها نحو 1.7GB. وجودها في مستودع عام واحد يجعل أول عملية push كبيرة؛ لذلك يجب الحفاظ على هذا المستودع مخصصاً للأصول وعدم خلطه بتاريخ الكود الخاص. النسخ المستقبلية يمكن نشرها كـGitHub Release bundles لكل سورة إذا احتجنا إلى تقليل عدد ملفات Git.
